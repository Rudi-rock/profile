# Rudra Pratap Singh | The Collection

A React + Vite personal portfolio that presents Rudra's projects as an editorial collection.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

The portfolio content lives in `src/data/portfolio.js`, so it can later be replaced by an API without changing the page components. The current contact form validates locally and opens a pre-filled email draft; no server credentials or mail provider are assumed.

`legacy-portfolio.html` is the original single-file source preserved during the migration.
